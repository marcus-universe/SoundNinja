# Adding Sounds

A board is empty until you add clips. SoundNinja can import files, whole folders, a recording, or a shared soundboard pack.

## Import audio files

1. Open **File → Import Audio Files**, or use **Import** in the navbar.
2. Pick one or more audio files.
3. Sounds land in the current tab.

## Import folders

1. Open **File → Import Folders** (or **Import Folders** in the navbar).
2. Add one or more folders. Drag to reorder them before you import.
3. Choose how they land:
   - **Import as Tabs** — each folder becomes its own tab
   - **Import to current Tab** — every file goes into the active tab

## Record a clip

Open the [Record Editor](/docs/recording-editor) from the **Record** button in the player bar. Capture, trim, then **Import selected** or **Import all** into the current tab or a tab you pick.

## Import a soundboard

**File → Import Soundboard** loads a shared pack. Packs are a `.zip` that contains `project.sninja` plus the sound files. After import, open the project and play.

You can also keep several projects (profiles). Use the project selector to switch boards.

## Relink missing files

If audio files move on disk, SoundNinja shows a **Missing sound files** dialog. Pick a folder to search and relink the clips.
