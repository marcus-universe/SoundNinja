# Theme Editor

The Theme Creator is the full visual editor for your board. Open it from **Settings → Main → Theme Creator**.

## Three tabs

1. **General** — theme name, shared colors, and font uploads (`.ttf` / `.otf`)
2. **Buttons** — sound button colors, type, layout, and GIF overlay
3. **Tabs** — tab bar colors, type, and border thickness

A live preview shows tabs and buttons as you edit.

## What you can change

- Primary and accent colors, backgrounds, button colors, tab colors
- Button and tab font family and size
- Button width, radius, border width, gaps, and padding
- GIF overlay opacity (normal and hover)

## Save and share

- **Export .css** — write a theme file you can back up or send to a friend
- **Add to Themes** — save the file into your Themes folder and apply it
- **Import .css** — load a built-in preset or a saved theme
- **Reset** — return to SoundNinja defaults

If you close the window with unsaved changes, SoundNinja asks you to save first.

## Without the full editor

In **Settings → Main** you can still:

- Pick a theme from the list
- Edit CSS variables live (**Custom CSS**)
- Import a theme file into the Themes folder
