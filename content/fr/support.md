# Support

SoundNinja est un projet communautaire en bêta précoce. Le plus rapide pour obtenir de l’aide, c’est GitHub.

## Signaler un bug ou poser une question

Ouvre une issue sur GitHub :

[github.com/marcus-universe/SoundNinja/issues](https://github.com/marcus-universe/SoundNinja/issues)

Indique ton OS, la version de SoundNinja (**Aide → Rechercher les mises à jour** ou **Paramètres → À propos**), et les étapes pour reproduire.

## E-mail

Contact du mainteneur : [contact@marcus-universe.de](mailto:contact@marcus-universe.de)

## Mises à jour

Dans l’app, utilise **Aide → Rechercher les mises à jour**. Les nouveaux builds apparaissent aussi sur la [page Télécharger](/download) et sur [GitHub Releases](https://github.com/marcus-universe/SoundNinja/releases).

## Contribuer

Les pull requests sont les bienvenues. Le repo de l’app est [github.com/marcus-universe/SoundNinja](https://github.com/marcus-universe/SoundNinja). Le projet est sous licence [GPL-3.0](https://github.com/marcus-universe/SoundNinja/blob/main/LICENSE).
