# 支持

SoundNinja 是处于早期测试阶段的社区项目。最快的求助方式是 GitHub。

## 报告问题或提问

在 GitHub 上开一个 issue：

[github.com/marcus-universe/SoundNinja/issues](https://github.com/marcus-universe/SoundNinja/issues)

请附上操作系统、SoundNinja 版本（**帮助 → 检查更新** 或 **设置 → 关于**）以及复现步骤。

## 邮箱

维护者联系：[contact@marcus-universe.de](mailto:contact@marcus-universe.de)

## 更新

在应用中使用 **帮助 → 检查更新**。新构建也会出现在[下载页](/download)和 [GitHub Releases](https://github.com/marcus-universe/SoundNinja/releases)。

## 贡献

欢迎拉取请求。应用仓库是 [github.com/marcus-universe/SoundNinja](https://github.com/marcus-universe/SoundNinja)。项目采用 [GPL-3.0](https://github.com/marcus-universe/SoundNinja/blob/main/LICENSE) 许可。
