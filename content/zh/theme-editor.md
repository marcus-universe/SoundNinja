# 主题编辑器

Theme Creator 是音板的完整可视化编辑器。从 **设置 → 主要 → Theme Creator** 打开。

## 三个标签页

1. **常规** — 主题名称、共用颜色和字体上传（`.ttf` / `.otf`）
2. **按钮** — 音效按钮颜色、字体、布局和 GIF 叠加
3. **标签页** — 标签栏颜色、字体和边框粗细

编辑时会显示标签页和按钮的实时预览。

## 可以改什么

- 主色和强调色、背景、按钮颜色、标签页颜色
- 按钮和标签页的字体系列与字号
- 按钮宽度、圆角、边框宽度、间距和内边距
- GIF 叠加不透明度（正常和悬停）

## 保存与分享

- **导出 .css** — 写出可备份或发给朋友的主题文件
- **添加到主题** — 保存到 Themes 文件夹并应用
- **导入 .css** — 加载内置预设或已保存的主题
- **重置** — 恢复 SoundNinja 默认值

若关闭窗口时有未保存更改，SoundNinja 会先询问是否保存。

## 不用完整编辑器

在 **设置 → 主要** 中你仍然可以：

- 从列表中选择主题
- 实时编辑 CSS 变量（**自定义 CSS**）
- 将主题文件导入 Themes 文件夹
