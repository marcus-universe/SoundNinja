# 整理音效

SoundNinja 面向大型音效库。用标签页、分组、搜索和快捷键，让需要的片段只需一点（或一键）。

## 标签页

- 用 **添加标签页** 新增，并指定颜色，便于快速扫视标签栏。
- **全部** 视图显示跨标签页的所有音效。
- 一个音效可以属于 **一个或多个标签页**。右键音效，用 **移动到标签页** 进行分配。

标签页过渡在 **设置 → 主要**：滑动、淡入淡出、逐个按钮，或无。

## 分组

自 v0.5.3 起，分隔符可以变成命名分组：

- 从上下文菜单添加、重命名或删除分组
- 拖动分组标题 — 子项一起移动
- 将音效拖入或拖出分组
- 设置分组边框颜色、名称颜色和按钮对齐（或使用标签页默认）

如果只需要视觉分隔，仍可添加普通 **分隔符**。

## 搜索

使用导航栏中的 **搜索** 字段。结果会随输入更新。

## 重新排序

在 **设置 → 行为** 中打开拖放（**允许重新排序**）。然后拖动音效和分组到目标位置。

## 批量编辑

多选音效，然后一次性改颜色、移到标签页或删除。

## 快捷键和音效 ID

每个音效都有 8 位 ID。从按钮上下文菜单或多选 ID 芯片复制。

打开 **设置 → 快捷键**，将按键绑定到音效 ID。全局快捷键可选。

[Bitfocus Companion](/docs/remote-control) 用同一个 ID 触发片段。

## GIF 和颜色

右键音效可设置单按钮颜色或 GIF / 图片背景。这与为整块音板设置样式的 [Theme Creator](/docs/theme-editor) 是分开的。
