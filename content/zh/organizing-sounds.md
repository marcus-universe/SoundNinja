# 整理音效

SoundNinja 面向大型音效库。用 **标签和筛选**、标签页、搜索、多选和快捷键，让需要的片段只需一点（或一键）。

## 标签页

- 用 **添加标签页** 新增，并指定颜色，便于快速扫视标签栏。
- **全部** 视图显示跨标签页的所有音效。
- 一个音效可以属于 **一个或多个标签页**。右键音效，用 **移动到标签页** 进行分配。

标签页过渡在 **设置 → 主要**：滑动、淡入淡出、逐个按钮，或无。

## 分组

自 v0.5.3 起，分隔符可以变成命名分组：

- 从上下文菜单添加、重命名或删除分组
- 拖动分组标题 — 子项一起移动
- 将音效拖入或拖出分组
- 设置分组边框颜色、名称颜色和按钮对齐（或使用标签页默认）

如果只需要视觉分隔，仍可添加普通 **分隔符**。

在音板空白处右键可 **添加分组**。

## 标签 / 筛选

标签可跨标签页使用。滑出的 **筛选** 面板（侧边栏 **筛选**）用来创建标签并筛选音板。

### 创建和编辑标签

1. 打开侧边栏的 **筛选**。
2. 在 **标签** 下用 **添加标签** — 填写名称和颜色。
3. 在同一列表中重命名、改色或 **删除标签**。
4. 若显示 **还没有标签**，先在这里添加再分配。

### 给音效打标签

右键音效 → **标签**（复选框）。一个音效可以有多个标签。若还没有标签，菜单会指向筛选面板。

### 筛选音板

- 在筛选面板或 **搜索栏下方的芯片** 中切换标签。
- 匹配为 **OR**：音效带有 **任一** 已选标签就会显示。
- 导航栏 **搜索** 与当前标签筛选做 **AND**（输入 + 标签一起）。
- 关掉芯片（或清空筛选）即可再看到整个标签页。

按钮上可显示彩色标签名。在 **设置 → 行为 → 显示标签徽章** 中开关。

## 排序

打开筛选面板并选择排序方式：

- **用户定义** — 你的标签页顺序，分组可见
- **名称**、**添加时间**、**播放时长** 或 **文件大小** — 扁平排序列表；这些模式下 **分组会隐藏**

按时长排序时，首次可能会预热时长元数据。

## 重新排序

在 **设置 → 行为** 中打开拖放（**允许重新排序**）。然后拖动音效和分组到目标位置。重新排序在 **用户定义** 排序下生效。

## 多选

在导航栏打开 **多选**，然后：

- 单击切换音效
- **Shift+单击** 从上次锚点选范围
- 在音板空白处拖出 **框选**
- 单击空白（或外部）清除选择

批量栏会显示数量，以及 **颜色**、**移动到标签页…**、**删除** 和 **完成**。

多选时，每个按钮显示 **8 位 ID 芯片**。右键芯片即可复制。

## 单音效音量

右键 → **音量**。将滑块从 0% 拖到 100%。**双击** 重置为 100%。

会与设置中的主输出音量叠加。

## 快捷键和音效 ID

每个音效都有 8 位 ID。从按钮上下文菜单（**复制 ID**）或多选 ID 芯片复制。

打开 **设置 → 快捷键**，将按键绑定到音效 ID。全局快捷键可选。上下文菜单的 **分配快捷键** 会跳转过去并预填 ID。

[Bitfocus Companion](/docs/remote-control) 用同一个 ID 触发片段。

## 背景图和颜色

右键音效可设置单按钮颜色或背景图。这与为整块音板设置样式的 [Theme Creator](/docs/theme-editor) 是分开的。

选择器是 **背景图** 对话框（PNG、JPEG、GIF、WebP）：

- **本地文件** — 添加文件夹、选单个文件、按文件名搜索、网格预览，或从库中移除文件夹
- **GifSnap** — 无需 API 密钥即可在线搜索 GIF。首次使用会询问是否允许向 GifSnap 发请求；搜索结果会缓存以减少流量。见 [GifSnap](https://gifsnap.com)。
- **KLIPY** — 在线搜索 GIF。在 **设置 → 行为** 中填入自己的 API 密钥。密钥不会存进项目文件。

选图后，可在按钮上平移和裁剪。
