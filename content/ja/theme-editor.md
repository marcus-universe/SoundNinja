# テーマエディター

Theme Creatorは、ボードの完全なビジュアルエディターです。**設定 → メイン → Theme Creator** から開きます。

## 3つのタブ

1. **一般** — テーマ名、共有色、フォントのアップロード（`.ttf` / `.otf`）
2. **ボタン** — サウンドボタンの色、書体、レイアウト、GIFオーバーレイ
3. **タブ** — タブバーの色、書体、枠線の太さ

編集中、ライブプレビューがタブとボタンを表示します。

## 変更できる項目

- プライマリとアクセントの色、背景、ボタン色、タブ色
- ボタンとタブのフォントファミリーとサイズ
- ボタンの幅、半径、枠線幅、隙間、パディング
- GIFオーバーレイの不透明度（通常とホバー）

## 保存と共有

- **.cssをエクスポート** — バックアップや友人への送信用テーマファイルを書き出す
- **テーマに追加** — Themesフォルダに保存して適用
- **.cssをインポート** — 組み込みプリセットまたは保存済みテーマを読み込む
- **リセット** — SoundNinjaのデフォルトに戻す

未保存の変更があるままウィンドウを閉じると、SoundNinjaが先に保存を求めます。

## フルエディターなしで

**設定 → メイン** でも次が可能です：

- リストからテーマを選ぶ
- CSS変数をライブ編集する（**カスタムCSS**）
- テーマファイルをThemesフォルダにインポートする
